# Historical source retained

The original validation runner produced the archived seed42 scores. Its helper
modules are in ../code/; this single archived runner is provenance, not a
standalone entry point. The main runner adds training histories and model/
expression exports. The original plot helper used identity lines and alphabetical
heatmap ordering; the current helper uses OLS-only and observed-derived clustering.
The Hi-C v2 raw-mapping script lacks its original base helper; see data docs.
No older unrelated experiments or workshop figures are substituted for main scores.
