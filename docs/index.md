# Graph-informed perturbation prediction

Two research approaches to held-out gene-combination response prediction: STRING-conditioned latent diffusion and a STRING-assisted interaction-transfer predictor.

This guide separates algorithms, benchmark reproduction, exploratory preprocessing and evidence. The result scope is the custom 101-pair Norman cohort; this is not established unseen-gene zero-shot prediction.
